# Weather

A SwiftUI weather app for iPhone.

- Current conditions, 24-hour and 7-day forecasts
- Feels-like, humidity, wind, UV index, sunrise/sunset, precipitation chance, pressure, cloud cover
- Background gradient that follows the conditions and time of day
- Current location (CoreLocation) or city search, with saved locations
- Celsius / Fahrenheit toggle, pull to refresh

Weather data comes from [Open-Meteo](https://open-meteo.com) and needs no API key.

Open `Weather.xcodeproj` in Xcode 16 or later and run the `Weather` scheme on an iPhone or simulator (iOS 18+).
